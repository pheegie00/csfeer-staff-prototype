# Project Overview

### Outcomes

- A platform that allows us to efficiently build user-friendly forms that share data with systems of use and record
- A form in production proving the value of the system
- Funding from program offices to build and manage their forms
- From PWS: "The scope for this system is an interface for OCS grant recipients to submit and manage submissions of pre-award and post-award information to ACF; an interface for ACF staff to review submitted information from grant recipients, and the ability to transmit the data collected via API endpoints and data download formats such as CSV for analysis and integration with other data tools"

**MVP Objectives**

- Develop a digital “forms engine” platform which supports basic features such as approvals, authentication, review memos or comments, revisions, exports, etc.
- Launch the “forms engine” in an initial pilot with selected recipients from Tribes and Tribal organizations, replacing 3 fillable PDFs:
  - CSBG Tribal Plan and Application
  - CSBG Tribal Annual Report (OMB Approved Form)
  - CSBG Tribal Annual Report [Short Form] (OMB Approved Form)

### Context

- Continually getting program offices asking if there is any GS alternative for grantees filling out form

  - Post-award financial forms: pushing towards PMS ![](/s/pc06xe/9109/5sz9el/_/images/icons/emoticons/help_16.svg)
  - Programmatic reporting - looking into an ACF-hosted, flexible option

    - Particularly interested when a form crosses program offices (rather than within 1 program office)
    - Examples: OCS CSBG, OFVPS (and others) 424M
- Building forms in GS is not user friendly, is expensive, and has a long timeline.

  - GS-forms data is not actionable by ACF staff
  - Many shadow systems have been put in place to gather data
  - Program offices are looking into building their own systems, which for some forms could like to duplication of effort and cost
