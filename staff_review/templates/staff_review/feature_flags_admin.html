How flags work

Toggling a flag off hides the nav link AND blocks the underlying URL with a friendly "feature disabled" page. Changes take effect immediately for every user. Re-enabling restores normal behavior. Adding a brand new flag in code defaults it to On until you explicitly turn it off here.
