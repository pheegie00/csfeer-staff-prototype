Federal Staff Portal

One place to review every program submission

CORE is the Administration for Children and Families' grant reporting platform. Federal staff use it to review, return, and close submissions across CSBG, LIHEAP, TANF, and every other ACF program in one consistent workflow.

What CORE handles for you

Built so program admins can self-serve and reviewers can move fast.

▤

Program-scoped inbox

Your inbox shows only the submissions for programs you're assigned to. OCS reviewers never see OFA work, and vice versa.

✓

Return and determine in one click

Send forms back for revision with itemized review comments, or record an Accept or Close determination with a rationale.

⚙

Per-program Form Builder

Program admins set submission windows, scope forms by org type, and publish new versions without a deploy.

☰

Audit log and CSV exports

Every action is tamper-evident and FISMA-aligned. Pull resolved submissions to CSV any time.

ⓘ

Role-filtered help

Quick start guides and a knowledge base scoped to your role, plus a search assistant that points you to the right article.

➤

Window and scope enforcement

Recipients only see forms their org is eligible for, and only when the submission window is open. No more guessing.
