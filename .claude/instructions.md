# CSFeer Project Instructions for Claude

## Critical Rules

### Docker-First Development
**ALWAYS run commands inside Docker containers. NEVER run Python/Django commands directly on the host.**

```bash
# ✅ CORRECT - Run commands in Docker
docker compose exec app python manage.py migrate
docker compose exec app python manage.py createsuperuser

# ❌ WRONG - Don't run directly on host
python manage.py migrate
uv run python manage.py migrate
```

### Container Access
```bash
# Access app container shell
docker compose exec app bash

# Access database
docker compose exec db psql -U csfeer

# View logs
docker compose logs -f app
```

## Project Architecture

### Technology Stack
- **Backend**: Django 5.2.7 + Python 3.12
- **Frontend**: USWDS (U.S. Web Design System) + AlpineJS + HTMX
- **Database**: PostgreSQL 16
- **Static Files**: WhiteNoise (no Nginx, no S3/CloudFront for MVP)
- **Deployment**: AWS ECS Fargate + RDS
- **Auth**: Keycloak OIDC (optional) + Django auth (fallback)

### Docker Services
- `app` - Django application at http://ui.csfeer:8000
- `db` - PostgreSQL at db.csfeer:5432
- `mock-oauth` - Keycloak at http://oauth.csfeer:8081

### Environment Variables Pattern
Uses double underscore `__` for nested config:
```bash
DB_CONFIG__PGHOST=localhost
DB_CONFIG__PGPASSWORD=secret
OIDC_CONFIG__CLIENT_SECRET=shhhh
```

### Starting Development Environment

### Running Django Commands
```bash

# Create superuser
docker compose exec app python manage.py createsuperuser

# Django shell
docker compose exec app python manage.py shell

# Load initial forms
docker compose exec app python manage.py load_initial_forms
```

### Static Files Workflow

**Frontend Build (when CSS/JS changes):**
```bash
# Rebuild frontend assets (runs on host, not in Docker)
npm run build

# Files output to: frontend/built/
# Then collected to: csfeer/static/frontend/ (via volume mount)
```

**Django collectstatic (for production builds):**
```bash
# Inside container for production
docker compose exec app python manage.py collectstatic --noinput

# This triggers WhiteNoise compression:
# - Creates .gz and .br compressed versions
# - Adds content-hash to filenames
# - Output to: staticfiles/
```

### WhiteNoise Configuration
- **Development (DEBUG=True)**: Serves from source directories
- **Production (DEBUG=False)**: Serves compressed, hashed files with immutable cache headers
- **Compression**: 88% reduction (575 KB → 69 KB for main CSS)
- **No Nginx needed**: Gunicorn + WhiteNoise handles everything

## AWS Deployment

### Deployment Script
```bash
# ALWAYS use this script for AWS deployments
./devops/iac/terraform/deploy-dev.sh

# Menu options:
# 1. Complete setup (all steps)
# 2. Setup infrastructure (S3, ECR, VPC)
# 3. Build and push Docker image
# 4. Deploy RDS
# 5. Deploy ECS/Fargate application
# 6. Show application status
# 7. Connect to container (shell)
# 8. Create superuser & organization
# 9. Teardown (destroy all resources)
# 10. Deploy new code (rebuild + redeploy)
```

### Infrastructure Components
- **S3**: Terraform state storage
- **ECR**: Docker image registry
- **RDS**: PostgreSQL database (t3.micro)
- **ECS/Fargate**: Container orchestration
- **ALB**: Application Load Balancer
- **VPC**: Default VPC with public subnets

### Docker Build for AWS
```bash
# Build for AWS Fargate (linux/amd64)
docker build --platform linux/amd64 -t csfeer:latest --target app .

# Push to ECR (done by deploy script)
# Deploy via terraform (done by deploy script)
```

## Common Issues & Solutions

### Database SSL Error
```bash
# If you see: "server does not support SSL, but SSL was required"
# Solution: Set DB_CONFIG__SSL_MODE=disable for local development
docker compose exec app bash
export DB_CONFIG__SSL_MODE=disable
python manage.py migrate
```

### Static Files Not Loading
```bash
# Rebuild frontend assets
npm run build

# Clear browser cache
# Check DEBUG setting (WhiteNoise behaves differently)
```

### Container Won't Start
```bash
# Check logs
docker compose logs app

# Common issues:
# - Database not ready (entrypoint waits for it)
# - Migration failures
# - Missing environment variables
```
