{# Renderer modules + WASM kernel served from Django staticfiles. We tried both esm.sh and JSDelivr's /+esm and both failed for the same reason: each peer-dep (@formspec-org/engine, .../layout, .../render) is served as its OWN ESM bundle, and the WASM-bridge module that holds the `_wasmReady` flag is bundled inside *each* of them separately. Calling `initFormspecEngine()` in one bundle leaves the render bundle's copy uninitialised -- the element then throws "Formspec runtime WASM is not initialized" the moment we set `.definition`. We sidestep that by bundling all four packages locally with esbuild (see tools/formspec-bundle/), which produces a single ESM file with exactly one WASM-bridge module instance shared between the engine, the render side, and the webcomponent. #}
