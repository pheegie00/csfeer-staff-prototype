# Overview

This folder contains ERD diagrams representing our database schema.

Diagrams can be manually generated by running:

```bash
# Generate all apps (default)
uv run python manage.py generate_er_diagram

# Generate specific app(s)
uv run python manage.py generate_er_diagram form_manager

# Generate multiple specific apps
uv run python manage.py generate_er_diagram form_manager auth
```

# Dependencies

You must install `graphviz` (`brew install graphviz`) for diagram generation to work.

Development dependencies:
```bash
uv sync
```

# Caveats

The diagrams are based on Django models, not the database itself:

* Table names use Django model class names
* Only models defined in Django apps are included
* Relationships shown are Django model relationships (ForeignKey, OneToOne, ManyToMany)
* Custom database tables or views not defined in Django models won't appear

# Format Options

```bash
# PNG (default)
uv run python manage.py generate_er_diagram --format png

# SVG
uv run python manage.py generate_er_diagram --format svg

# PDF
uv run python manage.py generate_er_diagram --format pdf

# DOT (GraphViz source)
uv run python manage.py generate_er_diagram --format dot
```

# Output

The command generates a single file: `csfeer.{format}` which is tracked in git.

Run the command after making model changes to update the diagram.
